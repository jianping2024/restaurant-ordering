# 本次改动业务场景测试报告：菜品销售方式堂食/外卖多选

日期：2026-10-29  
分支：`fix/menu-sales-channel-multiselect`  
UAT 基址：`http://localhost:3002`

## 1. 本次修改

- **内容：** 菜品「销售方式」改为堂食/外卖可单可双，与外卖耗材互斥；新增仅外卖 `takeaway_only`；堂食菜单/加单不含仅外卖；关总开关后仅外卖仍不进堂食。
- **文件：** `instore-takeaway.ts`、`MenuManager.tsx`、dashboard menu API、`resolve-append-cart-items.ts`、迁移、产品文档、场景本文。
- **角色：** 店主菜单；员工堂食/外卖点餐加单。

## 2. 核心业务规则

1. sole：`takeaway_role` = `none` | `sellable` | `takeaway_only` | `packaging`
2. 堂食菜单/加单：`none`/`sellable`；外卖：`sellable`/`takeaway_only`；耗材永不进点餐
3. 勾外卖须外卖价 > 0；价格字段始终单独填
4. 渠道都空 → 默认堂食；与耗材互斥

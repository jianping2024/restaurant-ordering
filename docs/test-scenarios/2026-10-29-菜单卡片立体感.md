# 本次改动业务场景测试报告 — 顾客菜单卡片立体感

## 1. 本次修改

- **内容：** 顾客菜单右侧菜品卡加立体层次：卡片顶部光泽 + 多层投影、缩略图内凹、鼠标悬停上浮并随指针轻微倾斜（≤4°/5°）、图片浮起；按住卡片下沉。金色 + 与数量条外观、交互不变。系统「减少动态效果」时关闭动画。
- **文件：** `globals.css`（`.mesa-menu-item-card` 立体样式）、`MenuItemCard.tsx`（指针写倾斜 CSS 变量）、`menu-item-card-layout.ts` / `.test.ts`（`mesa-menu-item-card-thumb` / `mesa-menu-item-card-action` 类名、`menuItemCardTiltFromPointer`）、`docs/agent-sole-index.zh.md`
- **角色 / 页面：** 顾客扫码菜单（经典 / 寿司）；员工「继续点餐」共用 `MenuItemCard`，同样生效
- **唯一写法：** 立体样式只在 `.mesa-menu-item-card` 一处（深色默认 + 浅色覆盖各一份）；倾斜只经 `menuItemCardTiltFromPointer`；不加 React state

## 2. 核心业务规则

1. 【本次新增】卡片静止时有可见层次，浅色 / 深色分别取各自投影色。
2. 【本次新增】仅鼠标（`hover: hover`）悬停时倾斜上浮；触屏不倾斜。
3. 【本次新增】按金色 + / 数量条时卡片不下沉；按卡片其他区域下沉。
4. 【已实现】金色 + → 数量条 −/n/+、自动收起、加减改购物车，行为不变。
5. 【本次新增】`prefers-reduced-motion: reduce` 时无过渡、无按压位移。

## 3. 详细测试场景

### 场景 1：深色主题浏览菜单

- **前置状态：** 白云 A-01 已开台，顾客手机/电脑打开菜单，默认深色。
- **操作过程：** 关闭寿司轮次说明 → 浏览鸡尾酒分类。
- **预期结果：** 卡片底部有投影与底色分离，缩略图白底四周有内凹阴影。
- **数据验证：** 计算样式 box-shadow 三层、`::after` inset 阴影存在。
- **标签：** 【已验证】

### 场景 2：切换到浅色主题

- **操作过程：** 点顶部「深色模式」开关切到浅色。
- **预期结果：** 投影变为暖棕色（70 50 20），顶光 0.6，卡片与米色底分得清。
- **标签：** 【已验证】

### 场景 3：电脑上鼠标悬停卡片

- **操作过程：** 鼠标移到「105 T-Quila Sunrise」卡片右上区域。
- **预期结果：** 卡片上浮 4px 并向指针方向倾斜，投影变长，酒瓶图放大 4% 上浮；移出后复原。
- **数据验证：** `--mesa-menu-card-tilt-x/y` = 1.95deg / 3.33deg，transform 为 matrix3d；图片 `matrix(1.04,…,-4)`。
- **标签：** 【已验证】

### 场景 4：加菜 → 数量条 → 减回 0（回归）

- **操作过程：** 点「103 Pina Colada」金色 + → 出现 −/1/+ → 点 −。
- **预期结果：** 数量条展开、显示 1；减到 0 收起回 +；底部合计复原 €55.90。
- **标签：** 【已验证】

### 场景 5：手机竖屏（375 宽）

- **操作过程：** 手机尺寸打开同一菜单。
- **预期结果：** 单列、缩略图 88px、无横向滚动；`hover:none` 不倾斜，静止投影仍在。
- **标签：** 【已验证】

### 场景 6：手指按住卡片下沉 / 按 + 不下沉

- **说明：** 浏览器自动化无法保持 `:active` 按压态；已确认 `:has()` 受支持、选择器存在并排除 `.mesa-menu-item-card-action`。
- **标签：** 【未验证】（需真机手指按住观察）

### 场景 7：系统开启「减少动态效果」

- **说明：** 预览面板无法模拟该系统设置；CSS 规则已存在。
- **标签：** 【未验证】

### 场景 8：员工「继续点餐」弹层

- **说明：** 共用同一 `MenuItemCard`，本轮未开员工端弹层目测。
- **标签：** 【未验证】

### 不适用维度

操作顺序 / 并发 / 本地与服务端状态 / 状态转换 / 历史数据 / 权限：本次纯样式 + 指针 CSS 变量，不碰数据、接口和购物车逻辑，不适用。

# 开台用缓存里的单价

## 1. 本次修改

空桌开台不再对每个套餐单独查价。版本和当前时段没变时，用手机上已经有的那份「能开的套餐 + 成人价、儿童价」。变了才要一整份新的。没有这两个价的套餐不出现在选项里。

## 2. 核心业务规则

- 版本号和当前时段都没变：不再查单价，继续用缓存。
- 版本或时段变了：要一份新名单，名单里每一项都带着成人价和儿童价。
- 没有这两个价的套餐不进选项，选项上也不再写「请到后台配置规则」。
- 一个都没有：只显示「当前时段没有可开的套餐」。
- 开台单选只画这一份名单，不再自己判断有没有价。
- 已经开台的那一桌，正在用的套餐仍可改人数。那一页仍按原来的方式查价，这次没改。
- 外卖开台不出现套餐选项，也不逐个查价。只确认开台。

## 3. 详细测试场景

### 场景 1：版本没变，直接用缓存

- **前置状态**：前台已登录白云，缓存里已有当前时段的套餐和单价。
- **操作过程**：再打开一张空桌的开台抽屉。
- **预期结果**：livre 和 UAT 都出现，并带上缓存里的单价。不再出现「当前时段无匹配价格」。
- **数据验证**：带上已知版本和时段再请求，返回 `unchanged: true`，没有 `prices`。
- **异常恢复**：缓存是旧格式（没有单价）时，自动要一次新名单，之后按新缓存用。

### 场景 2：没有价的套餐不出现

- **前置状态**：某个启用套餐在当前时段没有成人价和儿童价。
- **操作过程**：打开空桌开台抽屉。
- **预期结果**：这个套餐不在选项里，也不能点。
- **数据验证**：完整名单里没有它的 id，也没有它的价格。
- **异常恢复**：后台补上价格后，版本号变化，下次打开拿到新名单。

### 场景 3：外卖开台不带套餐

- **前置状态**：前台在楼面，点开一张空的外卖桌。
- **操作过程**：打开开台抽屉。
- **预期结果**：只有说明和确认，没有套餐单选，也没有「请到后台配置规则」。
- **数据验证**：不出现逐个查价的请求。
- **异常恢复**：取消后桌子仍是空的。

## 4. 实际测试结果

- 【已验证】白云 `restaurant-mohnrib5`，`http://localhost:3001`，前台 `qiantai1`。完整请求返回 livre 成人 19.95 / 儿童 10，UAT 成人 25 / 儿童 12。
- 【已验证】同一版本 `0`、同一时段再请求，返回 `unchanged: true`，没有 `prices`。
- 【已验证】空桌 A-02x 开台抽屉：Buffet livre 成人 €19.95 / 儿童 €10.00，UAT 第二套餐成人 €25.00 / 儿童 €12.00。点了 UAT，单价还在，没有「请到后台配置规则」。这次打开只请求了一次套餐名单，没有逐个查价。点了取消，桌子仍是空的。
- 【未验证】当前两个套餐都有价，没有另造一个没价的套餐来看它是否消失。
- 【未验证】外卖组里只有 A-20，已经开着。没有空的外卖桌可点开台抽屉。

# 本次改动业务场景测试报告 — 客人点餐窗标题只显示店名·桌号

日期：2026-10-28  
分支：`feat/guest-menu-title-no-menu`  
UAT 基址：`http://localhost:3005`（功能 worktree，非 `:3000`）

## 1. 本次修改

- **内容**：客人点餐页窗口/标签身份固定为 `店名 · 桌号`（无桌仅店名）；去掉写死「— 菜单」。网页标题与本桌应用名共用同一公式；已装应用窗口清空网页标题，避免 Chrome 拼成两截。
- **文件**：`site-manifest.ts`（`formatGuestTableWindowTitle`）、`[slug]/menu/page.tsx`、`GuestTableStandaloneTitle.tsx`、`MenuPage.tsx`、单测、设计/sole 文档、本报告。
- **角色 / 页面**：客人 `/{slug}/menu?table_id=…`（浏览器标签、已装应用窗口）。
- **唯一写法自检：** `formatGuestTableWindowTitle` 一份；`generateMetadata` + `buildGuestTableManifest` 只调用它；standalone 清空仅 `GuestTableStandaloneTitle`。

## 2. 核心业务规则

1. 有桌：身份文案 = `店名 · 桌号`（唯一公式）。
2. 无桌：身份文案 = `店名`。
3. 永不出现「菜单」后缀（不跟 UI 语言走）。
4. 浏览器标签：显示网页标题（上述文案）。
5. 已装应用窗口：栏上只留一截同一文案（应用名承载；standalone 下网页标题清空）。

## 3. 详细测试场景

### 场景 1：浏览器标签打开本桌点餐页

- **前置状态**：本地 Washoku（`lucky-tea-mulcs62n`），桌 `display_name=100`，`table_id=eade3420-ae66-478e-ad29-1fffb3da3d86`
- **操作过程**：普通浏览器打开  
  `http://localhost:3005/lucky-tea-mulcs62n/menu?table_id=eade3420-ae66-478e-ad29-1fffb3da3d86`
- **预期结果**：`<title>` / `document.title` = `Washoku Sushi · 100`；不含「菜单」；页内仍是 Washoku
- **数据验证**：HTML title 与 guest manifest `name` 同为 `Washoku Sushi · 100`
- **异常恢复**：刷新后标题不变

### 场景 2：公式无桌号分支（仅店名）

- **前置状态**：调用 `formatGuestTableWindowTitle({ restaurantName: 'Washoku Sushi' })`（无 `tableDisplayName`）
- **操作过程**：单测断言
- **预期结果**：返回 `Washoku Sushi`
- **数据验证：** 与有桌分支共用同一函数
- **说明：** 线上不带 `table_id` 时 `resolveCustomerTableContext` 仍可能落到某桌（既有行为）；纯「仅店名」由单测锁定

### 场景 3：已装应用窗口只显示一截

- **前置状态**：模拟 `display-mode: standalone`（Chrome 已装窗）
- **操作过程**：进本桌菜单后执行 standalone 清空逻辑（`GuestTableStandaloneTitle`）
- **预期结果**：`document.title` 变为空串；窗口栏只剩应用名 `店名 · 桌号` 一截
- **数据验证：** 应用名仍来自同一公式（manifest `name`）

### 场景 4：切换界面语言

- **前置状态**：场景 1 页面已打开
- **操作过程：** 若页上有语言切换，切到英/葡；或确认标题不走 i18n messages
- **预期结果：** 标题仍无中文「菜单」（公式不读 UI 语言包）
- **说明：** 标题字符串本身是店名·桌号，与语言无关

### 场景 5：回归 — guest manifest 契约

- **前置状态：** 同桌
- **操作过程：** GET  
  `/mesa-pwa-guest-table.webmanifest?slug=lucky-tea-mulcs62n&table_id=…`
- **预期结果：** `name` = `Washoku Sushi · 100`，`short_name` = `100`；`start_url` 为本桌菜单

### 场景 6：回归 — 菜单页仍可打开、店招正确

- **前置状态：** 场景 1
- **操作过程：** 浏览器打开菜单，看店招与桌号徽章
- **预期结果：** 店招 Washoku；桌号与 URL 桌一致；点餐壳可交互（不因标题改动黑屏）

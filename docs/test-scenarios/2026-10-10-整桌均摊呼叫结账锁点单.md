## 2. 核心业务规则

1. 【本次新增 / 恢复】整桌或均摊呼叫成功 → 会话 `billing` → 任何人不能再给该桌加菜。
2. 【已实现】按菜（`upsert` `by_item`）→ 会话保持 `open`。
3. 【已实现】员工「恢复点单」→ 会话回 `open` → 可再点。
4. 【已实现】桌级锁点单的唯一事实是会话 `billing`（读侧：`guestOrderingEnabled` / `loadAppendWriteContext` / `isCheckoutPending`）。写侧唯一闸：`upsert_bill_split_request` 内 `p_split_mode in ('whole_table','even')`。

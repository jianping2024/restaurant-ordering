客人点餐 · 按编码 / 名称直接定位

客人对照纸质菜单上的编号，或记得菜名时，在顶栏搜索框输入 → 选中结果 → 系统切到该菜所在分类并把列表滚到该菜卡（短暂高亮）。不改成「整页只剩搜索结果」的第二套菜单。

唯一能力：客人菜单菜品定位（输入 → 匹配 → 跳转），不另起筛选列表页。
匹配字段：菜品编码 item_code + 当前界面语言下的菜名（与屏上 formatMenuCatalogItemLabel 一致）。
放置：桌号顶栏下方全宽搜索条（sticky），不压左分类轨；推荐区与子分类 chip 仍按原顺序。
键盘：字号 ≥16px；有内容可一键清空；无结果时提示「没有找到」。
范围：仅当前客人可见目录（时段 / 堂食外卖通道过滤后的菜）；下架菜不进建议。

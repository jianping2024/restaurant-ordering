## 1. 本次修改

- **内容**：顾客手机「已呼叫结账」页，按菜分（by_item）时，「总计」改成整桌总额，下面列出已收款、已呼叫结账（待收）、待认领三笔；分单结果列出同桌所有人，自己置顶并带「我」。

## 2. 核心业务规则

1. 【本次新增】「总计」= 整桌账单总额，不再是本人那一份。
2. 【本次新增】已收款 + 已呼叫待收 + 待认领 = 整桌总额；待收、待认领为 0 时不显示该行。
3. 【本次新增】分单结果显示所有已呼叫的人，自己置顶带「我」，已收的人带「已收款」。
4. 【已实现】`bill_splits.result` 只存已呼叫的票，待认领 = 总额 − Σ 已呼叫金额。

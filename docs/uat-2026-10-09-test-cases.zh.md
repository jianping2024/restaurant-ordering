## 1. 员工结账台壳（列表 + 详情 page2）

**改动摘要：** 去掉楼面结账全屏层；员工结账只在 `/dashboard/checkout`；方式锁定；取消回桌台详情。

| ID | 场景 | 步骤 | 期望 |
|----|------|------|------|
| CHK-01 | 楼面待结账进结账台 | 桌有 `requested` 分单 → 点桌卡/入口进结账 | 进 `/dashboard/checkout?table_id=…`，**无**无列表全屏 sheet |
| CHK-02 | 桌面主从 | lg+ 打开结账台 | 左队列 + 右详情；未选桌右侧有提示 |
| CHK-03 | 手机列表/详情互斥 | 窄屏选一桌 → 「返回列表」 | 选桌后全屏详情；返回只回队列 |
| CHK-04 | 整桌未收款可改方式 | 新建整桌结账、未收款 | 可切到按菜 / 均摊 |
| CHK-05 | 均摊已提交锁定 | 均摊提交后未（或已）收款 | **不可**改回整桌/按菜 |
| CHK-06 | 按菜已提交锁定 | 按菜提交后 | **不可**改回整桌/均摊 |
| CHK-07 | 开收后锁定 | 任意方式已有收款 | 结账方式锁定 |
| CHK-08 | 均摊默认人数 | 新建均摊 | 默认 **1** 人，可加 |
| CHK-09 | 取消回桌台 | 详情点「取消」 | 回该桌桌台详情；队列里该单仍在 |
| CHK-10 | 恢复点单 | 有未结清结账单 → 「恢复点单」 | 会话可继续点单；已收台账不丢（若有已收） |

## 3. 开台人数为 0 · 软确认（不再硬拦呼叫）

**规则：** 呼叫结账不再因人数=0 返回 `guest_count_required`；结账台进详情且本店有自助餐、人数未确认时弹软确认。

| ID | 场景 | 步骤 | 期望 |
|----|------|------|------|
| HC-01 | 员工呼叫 · 人数 0 | 开台人数 0 → 桌台详情「呼叫结账」 | API/流程成功进结账；**不**因人数拦死 |
| HC-02 | 顾客呼叫 · 人数 0 | 顾客账单「呼叫结账」（整桌/均摊） | 成功进入等待收款；不因人数失败 |
| HC-03 | 按菜个人呼叫 · 人数 0 | 人数 0 → 顾客按菜呼叫 | 成功（不因人数拦） |
| HC-04 | 有自助餐 · 进详情弹窗 | 人数 0 的结账单 → 员工打开详情 | 弹「开台人数为 0，是否确认？」 |
| HC-05 | 确认后本单不再弹 | 弹窗点确认 → 离开再进同一单 | **不再**弹；可继续收款 |
| HC-06 | 调整人数 | 弹窗选调整人数 → 改成人/儿童并保存 | 结账单金额/人数刷新；可收款 |
| HC-07 | 无自助餐店 | 无 active buffet 的店 · 人数 0 进详情 | **不**弹零人数确认 |
| HC-08 | 人数已确认 | 开台时已填人数 >0 进详情 | 不弹 |

## 4. 功能开关：关台结账 `quick_table_close`（与打印发票互斥）

**规则：** `quick_table_close` 开 → 楼面显示「关台结账」、隐藏「呼叫结账」；顾客手机呼叫结账照常；员工 ensure-entry 关掉；与 `bill_sync_to_fiscal` 互斥。

| ID | 场景 | 步骤 | 期望 |
|----|------|------|------|
| QC-01 | 默认关 | `quick_table_close=false`，有 `tables.checkout_close` | 桌台详情有「呼叫结账」；**无**「关台结账」 |
| QC-02 | 打开关台结账 | 设置里打开 `quick_table_close` | `bill_sync_to_fiscal` 被关掉；楼面变「关台结账」 |
| QC-03 | 打开打印发票 | 再开 `bill_sync_to_fiscal` | `quick_table_close` 关掉；恢复「呼叫结账」 |
| QC-04 | 关台结账成功 | 开台有消费 → 「关台结账」确认 | 会话关闭；写入 settled 应付快照；桌变空闲 |
| QC-05 | 关台结账 + 打总单 | 确认时勾选打印账单（若 UI 有） | 关台成功；打印失败**不**挡关台（可观察 print_ok） |
| QC-06 | 无结账权限 | 角色无 `tables.checkout_close` | 无「呼叫结账」也无「关台结账」 |
| QC-07 | 顾客呼叫照常 | `quick_table_close` 开 → 顾客账单呼叫结账 | 有「呼叫结账」按钮；API 可成功 |
| QC-08 | ensure-entry 被挡 | 开关开时员工走 ensure-entry | 被拒或入口不可点 |
| QC-09 | 强制关台仍在 | 有 `tables.force_close` | 「强制关台」仍可用（与关台结账独立） |

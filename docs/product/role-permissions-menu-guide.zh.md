# 角色权限：菜单定位与功能说明

> **状态**：与线上编辑器一致（`ROLE_PERMISSION_PAGE_TREE`）  
> **入口**：顶栏 / 主导航 → **餐厅设置** → **角色权限**（`/dashboard/settings/roles`）  
> **谁能改**：持有「角色权限」子权限的账号（通常是店主）；店主账号本身能力恒为全开，不靠本页勾选约束自己。

本文按**角色权限编辑页上的勾选顺序**，说明每一项：

1. **勾选文案**：页上看到的中文名（与产品界面同源）  
2. **菜单定位**：员工拿到权限后，从哪里点进对应功能  
3. **功能说明**：勾上之后能做什么；未勾时会怎样  

嵌套项须先勾父项（例如先有「结账请求」页，子按钮才有意义）。标「高危」的项在编辑页有敏感提示。

---

## 怎么读「菜单定位」

| 写法 | 含义 |
|------|------|
| **顶栏 / 主导航 →「某某」** | Dashboard 顶栏主导航入口（手机上可能在「更多」里） |
| **餐厅设置 →「某某」Tab** | 先有「餐厅设置」入口，再进设置页左侧/顶部的子 Tab |
| **楼面看板 → 桌台详情 →「某某」** | 先开楼面看板，点进某桌详情，再点该按钮 |
| **结账请求 → 详情 →「某某」** | 先开结账列表，再进某笔结账详情 |

路径示例中的 `{slug}` 为餐厅短名（URL 里的店代号）。

## 6. 结账请求（页入口）

| | |
|--|--|
| **勾选文案** | 结账请求 |
| **权限 key** | `dashboard.checkout.view` |
| **菜单定位** | 顶栏 / 主导航 → **结账请求**（`/dashboard/checkout`） |
| **功能说明** | 打开待结账 / 结账列表。子项控制页内关键按钮与相关 API。 |

### 6.1 确认收款（高危）

| | |
|--|--|
| **勾选文案** | 确认收款 |
| **权限 key** | `checkout.confirm_payment` |
| **菜单定位** | 结账请求 → 打开某笔结账详情 → **确认收款 / 收款** |
| **功能说明** | 把顾客已付金额记入台账并推进结账。最后一笔收齐时通常会连带关台。属敏感写操作。 |

### 6.2 折扣（高危）

| | |
|--|--|
| **勾选文案** | 折扣 |
| **权限 key** | `checkout.apply_discount` |
| **菜单定位** | 结账请求 → 结账详情 → **折扣**相关控件 |
| **功能说明** | 在收款前给账单打折。依赖「确认收款」；未勾确认收款时单独勾折扣无业务意义。属敏感。 |

### 6.3 整桌发起结账

| | |
|--|--|
| **勾选文案** | 整桌发起结账 |
| **权限 key** | `checkout.request_whole_table` |
| **菜单定位** | 结账 / 账单相关流程中「整桌结账」发起（与协助结账同属结账请求能力族） |
| **功能说明** | 允许按整桌方式发起结账请求（进入结账队列/详情的前置能力之一）。 |

### 6.4 协助结账

| | |
|--|--|
| **勾选文案** | 协助结账 |
| **权限 key** | `checkout.assist_bill` |
| **菜单定位** | 楼面或结账侧「协助顾客结账」入口（与 `checkout.request_whole_table` 同属结账请求调用族） |
| **功能说明** | 允许员工协助发起/进入结账流程（例如帮顾客把桌台送进结账）。未勾时相关协助入口不可用。 |

### 6.5 打印预结单

| | |
|--|--|
| **勾选文案** | 打印预结单 |
| **权限 key** | `checkout.print_pre_bill` |
| **菜单定位** | 结账详情或楼面关台结账路径上的 **预结单 / 关台打印账单** |
| **功能说明** | 允许打印预结单；在「关台结账」开启时，关台路径也可据此排队打账单。具体是否出纸还受打印设置开关影响。 |

### 6.6 待结账桌台

| | |
|--|--|
| **勾选文案** | 待结账桌台 |
| **权限 key** | `checkout.open_pending_tables` |
| **菜单定位** | 结账请求页内打开仍处于结账中的桌台相关入口 |
| **功能说明** | 允许从结账侧打开「正在结账」的桌台上下文。未勾时不能用该快捷入口。 |

### 6.7 同步账单

| | |
|--|--|
| **勾选文案** | 同步账单 |
| **权限 key** | `checkout.sync_bill` |
| **菜单定位** | 结账请求 → 结账详情 → **同步账单** |
| **功能说明** | 把本桌账单同步到财政/开票侧队列。实际能否入队还须店级功能开关打开；产品上常与「呼叫结账」能力一并校验。 |

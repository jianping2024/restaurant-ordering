# 浇头子集只显示已选

## 本次修改

- 后台菜品编辑：不勾「该类全部」时，主区**只显示已选浇头**；「添加浇头」从本类剩余里挑（可搜）
- 子集至少留一个（空 `item_ids` 仍表示该类全部）
- 角色/页面：店员 Dashboard → Menu → 编辑菜品 → 浇头

## 核心业务规则

1. `item_ids` 空 = 该类全部；非空 = 子集
2. 子集 UI 不整类铺 chip
3. 取消已选时至少留一个

## 详细测试场景

### 场景 1：取消「该类全部」后只见已选【已验证】

- **前置**：Washoku；Takoyaki 浇头曾勾「该类全部」
- **操作**：编辑 → 取消「Todos os pratos desta categoria」
- **预期**：主区只出现 1 个已选 chip（种子菜）+「Adicionar cobertura」；不见整类几十个未选 chip
- **数据验证**：实点 localhost:3000；快照仅 Harumaki 等已选
- **异常恢复**：取消关闭弹窗不保存

### 场景 2：添加浇头【已验证】

- **操作**：点「Adicionar cobertura」→ 出现搜索与未选列表 → 点 SALADA KAISEN
- **预期**：已选变为 2 个；主区仍不铺整类
- **数据验证**：DOM 已选 count=2
- **异常恢复**：点取消不写库

### 场景 3：威士忌大类回归【未验证】

- **说明**：Will 截图场景（威士忌类多菜）；本轮用 FRITA/Takoyaki 等价验证结构。大类可人工再点一次。

## 实际测试结果

| 场景 | 结果 |
|---|---|
| 1 只显示已选 | 【已验证】pass |
| 2 添加 | 【已验证】pass |
| 3 威士忌大类 | 【未验证】人工可选做 |

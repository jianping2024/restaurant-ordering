时间线（一人呼叫 → 其他人）

  1. A 本机草稿认领剩余菜 → 点呼叫 → 服务端 individual_checkout_apply 写入票并锁菜。
  2. 同事务插入 table_checkout_signals（call：名字 + 菜行 + 金额）。
  3. B 匿名 Realtime 收到门铃 → 拉新信号 → 弹框 + refreshBill。
  4. B 认票区按最新 persons 重算「别人已领 / 剩余」；超领标红；呼叫 CTA 在冲突或无可领时不可提交。
  5. 若信号晚到、B 抢先提交：服务端 claim_conflict 拒绝，并刷新账单（文案：有菜已被其他人认领）。

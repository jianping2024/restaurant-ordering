# 本次改动业务场景测试报告：订阅报价 = 基础版 + Pro 功能

## 1. 本次修改

- **内容：** 新增基础版价目表；全局定价可改基础月/年价；每店报价 = 基础 + 已勾 Pro 功能；零勾选 = 只要基础。
- **文件：** 迁移 `subscription_base_product`；`quoteRestaurantSubscriptionEur`；Ops 订阅定价页与餐厅 Pro 面板；文档。
- **角色 / 页面：** Ops 管理员（定价 + 餐厅详情报价）。

## 2. 核心业务规则

1. 基础版价目单独存，不进 Pro 功能键 / grant。【本次新增】
2. 店报价唯一公式：`quoteRestaurantSubscriptionEur` = 基础同周期价 + `quoteProFeaturesEur`。【本次新增】
3. Pro 能不能用仍看有效 Pro × grant，与报价分开。【已实现】

## 3. 详细测试场景

### 场景 1：保存基础价

- **前置：** Ops admin 已登录
- **操作：** 打开 `/ops/settings/pro`，改基础月价/年价并保存（连同 Pro 价目）
- **预期：** 200；库 `subscription_base_product` 更新
- **标签：** 【已验证】见实际结果

### 场景 2：零 Pro 勾选 = 只要基础

- **前置：** 基础月价非 0；店无 Pro 功能勾选
- **操作：** 看餐厅详情报价
- **预期：** Pro 功能小计 0；合计 = 基础
- **标签：** 【已验证】

### 场景 3：基础 + 勾选 Pro

- **前置：** 基础与功能价均非 0；勾选部分功能
- **操作：** 看报价拆分与合计
- **预期：** 合计 = 基础 + 勾选项之和
- **标签：** 【已验证】

### 场景 4：单元公式

- **操作：** `premium-tier` 单测
- **预期：** `quoteRestaurantSubscriptionEur` 与拆分一致
- **标签：** 【已验证】

### 场景 5：判权回归

- **预期：** 改基础价不影响 grant / 403 闸
- **标签：** 【未验证】本轮聚焦报价（判权代码未改）

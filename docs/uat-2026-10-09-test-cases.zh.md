## B. 员工结账台（优先）

### B1. 进结账台长什么样

1. 某桌客人已呼叫结账 → 从楼面进结账。  
   **过：** 进结账台页面；不是楼面弹一层全屏盖住。  
2. 电脑宽屏打开结账台。  
   **过：** 左边待结列表、右边详情；没选桌时右边有提示。  
3. 手机窄屏：点一桌 → 再点「返回列表」。  
   **过：** 点开后整屏是详情；返回后只剩列表。

### B2. 结账方式能不能改

1. 新建整桌结账、还没收款。  
   **过：** 还能切到「按菜」「均摊」。  
2. 选均摊并提交后。  
   **过：** 不能再改回整桌/按菜；默认人数是 **1**，能加。  
3. 选按菜并提交后。  
   **过：** 不能再改回整桌/均摊。  
4. 任意方式先收了一笔钱。  
   **过：** 结账方式锁死，不能再改。

### B3. 取消、恢复、本桌菜、收款钮

1. 详情点「取消」。  
   **过：** 回到这桌的桌台详情；结账队列里这单还在。  
2. 有未结清的结账单 → 点「恢复点单」。  
   **过：** 桌上能继续点菜；已经收过的钱还在。  
3. 打开整桌/均摊/按菜详情。  
   **过：** 有「本桌菜品」可展开；道数对得上。  
4. 看「收款」按钮。  
   **过：** 明显比旁边次要按钮宽、高大约一截（约 52px 高）；整桌/均摊/按菜同一套大小。

### B4. 队列空了往哪走

1. 结账台里做过待结单 → 收完最后一单（打印询问关掉）。  
   **过：** 自动回到楼面看板。  
2. 直接打开空的结账台（这页从没见过待结单）。  
   **过：** 停在空结账台，不跳楼面。

## C. 开台人数是 0

**规则：** 人数 0 也能呼叫结账；有自助餐的店，员工进结账详情时会问一句「人数是 0，确认吗？」。

1. 开台人数填 0，加一点消费 → 员工「呼叫结账」。  
   **过：** 能进结账，不被人数拦住。  
2. 同上，顾客手机整桌/均摊/按菜呼叫。  
   **过：** 同样成功。  
3. 人数 0 的结账单 → 员工打开详情。  
   **过：** 弹出零人数确认。  
4. 弹窗点确认 → 离开再进同一单。  
   **过：** 不再弹；能收款。  
5. 弹窗里改成人/儿童并保存。  
   **过：** 金额和人数更新，能收款。  
6. 开台时人数已经 >0。  
   **过：** 不弹零人数确认。  
7. （可选）没有自助餐的店、人数 0。  
   **过：** 不弹零人数确认。

## D. 「关台结账」开关

在老板设置里找功能开关。开「关台结账」时，会关掉「打印发票」；反过来开「打印发票」会关掉「关台结账」。

1. 默认关台结账关着。  
   **过：** 桌台详情有「呼叫结账」，没有「关台结账」。  
2. 打开关台结账。  
   **过：** 打印发票被关掉；楼面变成「关台结账」。  
3. 再打开打印发票。  
   **过：** 关台结账关掉；楼面又变回「呼叫结账」。  
4. 关台结账开着 → 有消费桌点「关台结账」确认。  
   **过：** 桌关了、变空闲。  
5. （可选）确认时勾选打账单。  
   **过：** 能关台；打印机挂了也不挡关台。  
6. 关台结账开着 → 顾客手机仍可「呼叫结账」。  
   **过：** 客人侧照常。  
7. 关台结账开着 → 员工不能再用「进结账台代开单」那条入口（或点了被拒）。  
8. 有强制关台权限时，「强制关台」仍在。

测完把开关恢复成你店平时要用的状态。

5. 改完人数再进一次账单。

7. 手机 A 一直停在账单编辑、从没呼叫 → 别人路径把桌结清关了。  
   **过：** A 也进已结清；没有可呼叫底栏。  
8. 已结清面。  
   **过：** 能评价或跳过；不自动进菜单。

## N. 容易踩坑的几条

1. 正常呼叫 → 收齐关台 → 顾客停已结清面。  
2. 打印发票开着时：楼面是「呼叫结账」路径；打印发票不关台。  
3. 空桌（几乎没消费）去结账：应被拦住。  
4. 两桌编成同行组 → 任一侧呼叫结账：应提示要先并桌/不能直接呼叫。  
5. 楼面一直开着 → 另一边改桌态（开台等）：这页桌卡自己变，不用切走再切回来才更新。  
6. 均摊收 1 人 → 恢复 → 再加菜再结：已收还在，方式仍锁。  
7. 按菜：手机 A 呼叫、手机 B 继续点并认领呼叫：桌不整桌锁死；两票分开收。  
8. 两人未付 → 连续收两人：两人都已收；只关台一次。

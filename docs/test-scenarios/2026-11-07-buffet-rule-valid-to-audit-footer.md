# 2026-11-07 自助餐价格：长期有效 + 钉底保存 + 操作记录

## 本次修改

- 价格规则弹窗：取消/保存钉在 `Modal` footer
- `valid_to` 可空 = 长期；新建默认无结束日；迁移批量清空旧结束日
- 价格规则 / 日历 / 周五晚策略写入 `operation_logs`
- 文档唯一口径：`docs/buffet-pricing-design.zh.md`、`docs/product/02-feature-map.md`、`docs/ai-schema.md`

## 核心业务规则

1. 计价：里斯本当日 ≥ 启用日，且（无结束日或当日 ≤ 结束日）
2. 常驻价默认长期；限时活动才填结束日
3. 页面改配置记操作记录；迁移清空结束日不记
4. 确认行唯一挂在 Modal footer

## 详细测试场景

### 场景 1：新增价格默认长期并钉底保存

- **前置状态：** 店主登录；自助餐设置有至少一套餐与时段
- **操作过程：** 打开「新增价格」→ 压矮视口滚到备注 → 看底部按钮 → 不填结束日 → 保存
- **预期结果：** 取消/保存始终钉底；保存成功；列表结束日显示「长期」
- **数据验证：** `buffet_price_rules.valid_to` 为 null；操作记录有 `BUFFET_PRICE_RULE` 新建

### 场景 2：设结束日为昨天则匹配不到

- **前置状态：** 场景 1 的长期规则（或任意启用规则）
- **操作过程：** 编辑该规则，结束日设为昨天并保存；价格预览用今日
- **预期结果：** 预览无价或该维度无命中；操作记录有修改详情

### 场景 3：日历标记记日志

- **前置状态：** 店主在自助餐「特殊日期」
- **操作过程：** 添加单日节假日标记
- **预期结果：** 操作记录出现 `BUFFET_CALENDAR`

### 场景 4：回归开台出到价

- **前置状态：** 平日长期规则覆盖当前时段
- **操作过程：** 服务员开台选该自助餐
- **预期结果：** 能解析出成人/儿童价（迁移清空结束日后仍可用）

# 本次改动业务场景测试报告：备餐成功不自动展开补打区

日期：2026-10-22  
分支：`fix/kitchen-prep-no-auto-ready-rail`

## 1. 本次修改

- **内容**：厨师点「备餐」（备餐区按钮 / 行右滑 / 共享备餐区）成功后，档口底栏「补打区 · 已备餐 / 已出餐」**不再自动展开**；开合只靠底栏「已备餐/已出餐 · n」/「收起」。
- **文件**：
  - `apps/web/src/components/kitchen/use-kitchen-prep-trays.ts`（`runPrep` 去掉成功后的 `setRailOpen(..., true)`）
  - `docs/product/station-kitchen-screens.zh.md`、`docs/agent-sole-index.zh.md`（与代码同一口径）
- **角色 / 页面**：后厨大屏档口（厨房 board）
- **流程**：勾选待备菜 → 备餐 → toast「已备餐」→ 菜进底栏计数；补打区保持收起，除非人手点开

## 2. 核心业务规则

1. 【本次新增】底栏补打区开合**唯一**由底栏按钮控制；备餐成功路径不得改开合状态。
2. 【已实现】备餐成功仍清备餐区勾选，并 toast「已备餐」；菜从工作台进底栏份数（状态仍为 `cooking` 等既有规则）。
3. 【已实现】人手展开后仍可勾选补打、点「打印」；收起行为不变。
4. 【已实现】备餐失败不误开补打区；空选点备餐只提示勾选。

## 3. 详细测试场景

### 场景 1：备餐区按钮备餐成功 — 补打区保持收起

- **前置状态**：后厨员工打开某大屏档口；工作台有待备菜；底栏补打区为收起。
- **操作过程**：勾选 ≥1 道 → 备餐区点「备餐」。
- **预期结果**：toast「已备餐」；勾选离开备餐区/工作台；**不出现**「补打区 · 已备餐 / 已出餐」展开面板；底栏按钮文案仍为「已备餐/已出餐 · n」（n 可增加）。
- **数据验证**：对应行不再是工作台 `pending`；底栏份数增加。
- **异常恢复**：刷新大屏后补打区仍默认收起；可再点底栏展开。
- **标签**：【已验证】

### 场景 2：人手展开补打区仍可用

- **前置状态**：场景 1 之后，底栏有已备餐份数。
- **操作过程**：点「已备餐/已出餐 · n」（葡语 UI：`Preparado / pronto · n`）→ 展开 → 点「收起」（`Ocultar`）。
- **预期结果**：展开见区标题与分组（含刚备的 Mojito）；收起后面板消失。
- **数据验证**：本改动不改打印语义（本轮未点打印）。
- **异常恢复**：收起后再备餐，仍不自动展开。
- **标签**：【已验证】

### 场景 3：备餐前补打区已展开 — 备餐不强制收起也不另开一层

- **前置状态**：人手已展开补打区。
- **操作过程**：再加一道待备菜 → 勾选 → 点「备餐」。
- **预期结果**：备餐成功；补打区**保持展开**；份数增加；不出现第二套弹层。
- **数据验证**：新备的菜出现在已展开的补打列表中。
- **异常恢复**：点「收起」可正常收起。
- **标签**：【已验证】

### 场景 4：行右滑备餐 — 同样不自动展开

- **前置状态**：底栏收起；工作台有可滑行备餐的行。
- **操作过程**：对一行右滑过阈值松手。
- **预期结果**：该行备餐成功；补打区不自动展开。
- **数据验证**：与场景 1 同一 `runPrep` 路径。
- **异常恢复**：同场景 1。
- **标签**：【未验证】（与场景 1 同代码路径；本轮以备餐区按钮 + API 为主，滑行未单独点）

### 场景 5：空选点备餐

- **前置状态**：备餐区无已选。
- **操作过程**：点「备餐」。
- **预期结果**：提示勾选；不展开补打区；无状态写。
- **数据验证**：无 prep API 成功写。
- **异常恢复**：勾选后再备正常。
- **标签**：【未验证】（既有行为，本改动未碰空选分支）

### 场景 6：回归 — 多档口共享备餐区（若大屏开了共享）

- **前置状态**：≥2 档口且开了共享备餐区。
- **操作过程**：跨档口勾选 → 共享区点「备餐」。
- **预期结果**：各档口成功清勾选；**任一档口**补打区都不因成功而自动展开。
- **数据验证**：同 `runPrep` 循环，已无 `setRailOpen(..., true)`。
- **异常恢复**：失败档口勾选保留（既有）。
- **标签**：【未验证】（本轮单档口/按按钮路径覆盖；代码路径已确认无自动开）

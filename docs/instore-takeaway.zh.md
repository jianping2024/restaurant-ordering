# 店内外卖（需求定稿）

> **状态：需求已定稿，待实施**
> 关联：[桌位分组](./restaurant-table-groups.zh.md) · [功能开关](./restaurant-features.zh.md) · [加单价格可信](./menu-order-append-price-trust.zh.md)

---

## 0. 一句话与边界

**店内外卖** = 店主建一个「外卖组」，组内桌台扫码或员工代点时只看到「可外卖」菜品、按外卖价下单；出单、结账、开票、关台与堂食完全相同；外卖桌结账时员工手动加「打包类」商品（餐盒/杯等）。

| 名称 | 含义 | 与本需求关系 |
|------|------|--------------|
| 店内外卖 | 本文档的新功能 | — |
| 现有「打包费」TAKEAWAY（`OrderItemKind 'takeaway'`，`takeaway_vat_rate`，收银员手填单价） | **堂食**没吃完打包带走的费用 | **保持不变**；外卖桌结账界面隐藏该按钮 |
| 打包类商品（新） | 外卖用的餐盒、杯子等 | 仅外卖桌结账时添加 |

---

## 1. 全链路总览

```
① 总开关「店内外卖」开启
   │
   ├─② 桌位分组：把一个分组设为「外卖组」（全店唯一）
   │      └─ 组内桌台 = 外卖桌（楼面看板中外卖组固定排最左）
   │
   ├─③ 菜品：勾「可外卖」+ 外卖价（必填 > 0）
   │
   └─④ 菜品类别：把一个类别设为「打包类」（全店唯一，无子类）
          └─ 类内商品 = 打包商品（不进任何点餐菜单）

⑤ 员工在楼面看板外卖组开单（无人数、无自助基价）
   └─ 开台小票开关开 → 打印外卖开台小票（含扫码点餐二维码）

⑥ 点单：员工代点 或 客人扫码（普通点餐页）
   └─ 只显示可外卖菜品 · 外卖价 · 服务端同一规则校验与定价

⑦ 出单：档口小票 / 厨房屏照常，标「外卖」

⑧ 结账：与堂食相同（含分单）
   └─ 员工手动加打包商品（选商品 + 数量）

⑨ 收款 · 开票 · 关台：与堂食相同
```

## 2. 总开关「店内外卖」

| 项 | 规则 |
|----|------|
| 位置 | 功能开关页，唯一编辑入口 `FeatureFlagsManager`；flag 键 `takeaway_ordering`，默认关 |
| 权限 | `settings.features.manage` |
| 开启后解锁 | 桌位分组「设为外卖组」、菜品类别「设为打包类」、菜品表单「可外卖 / 外卖价」 |
| 关闭前检查 | 外卖组有未结账桌台（会话 open/billing）→ **不允许关闭**，提示：「外卖组还有未结账的桌台」 |
| 关闭二次确认 | 标题「关闭店内外卖？」，正文「外卖组的桌台将变回堂食桌。」，按钮〔取消〕〔确认关闭〕（危险色） |
| 关闭后 | 外卖组**变回普通分组**：桌位管理与楼面看板照常显示（组名、组员不变；「设为外卖组」开关隐藏），看板分区不再固定最左、按原 `sort_order` 排；组内桌台按堂食处理（开台选人数/套餐、全部菜品、堂食价）；打包类商品**仍不进**点餐菜单（打包类身份不随开关改变，见 §5）；菜品可外卖 / 外卖价、外卖组标记、打包类标记**全部保留不删**，只隐藏；重新开启即恢复 |

## 3. 外卖组（桌位分组）

| 项 | 规则 |
|----|------|
| 设置位置 | 桌位管理 → 分组管理，分组新增/编辑加开关「设为外卖组」；总开关关闭时不显示 |
| 唯一性 | 全店最多一个外卖组（DB 部分唯一索引保证）；已有外卖组时，其它分组开关置灰并说明原因 |
| 外卖桌 | 外卖组内的桌台；与普通桌一样有桌号、二维码；QR 卡片/打印显示分组名 |
| 楼面看板 | 总开关开启时，外卖组分区固定排在分组行**最左**，不受分组 `sort_order` 影响；入口即此分区，不另加按钮 |
| 总开关关闭时 | 变回普通分组（见 §2），标记保留，重新开启自动恢复 |
| 变更锁 | 组内任一桌台有进行中的会话时，**不允许**：增删组员、取消外卖组标记、删除外卖组 |
| 转台 / 并台 | 外卖桌 ↔ 堂食桌**禁止**转台、并台（前端隐藏 + RPC 拒绝） |
| 拼桌 | 外卖桌不能加入拼桌组 |

---

## 4. 菜品「可外卖」

| 项 | 规则 |
|----|------|
| 表单 | 价格下方：开关「可外卖」；打开后显示「外卖价」，**必填且 > 0** |
| 总开关关闭时 | 两个字段隐藏且不校验，不影响普通保存；值保留 |
| 税率 | 外卖下单的税率 = 该菜 `vat_rate`（与堂食一致） |
| 菜品列表 | 信息行（meta）显示「外卖 €x」；标题仍为 `formatMenuCatalogItemLabel` |
| 价格快照 | 已下单的行保持下单时价格；改外卖价只影响之后的新单 |
| 打包类商品 | 表单不显示「可外卖」（见 §5） |

---

## 5. 打包类别与打包商品

| 项 | 规则 |
|----|------|
| 设置位置 | 菜品类别编辑加开关「设为打包类」；总开关关闭时不显示 |
| 唯一性 | 全店最多一个打包类（DB 部分唯一索引） |
| 结构 | 打包类必须是**单个类别、没有子类别**；有子类别的类别不能设为打包类，打包类下不能再建子类别 |
| 设为打包类的前置条件 | 类别内有「可外卖」或「推荐」的菜品 → **不允许**设置；否则弹一句确认：「该类商品将不再出现在点餐菜单中」 |
| 菜单可见性 | 打包商品**不出现在任何点餐菜单**（客人扫码、员工代点、堂食、外卖） |
| 打包商品表单 | 隐藏：可外卖、外卖价、推荐、时段、档口、口味、过敏原；**商品编码必填**（开票用） |
| 使用场景 | 仅外卖桌结账时手动添加（§8） |

## 6. 外卖桌开单与点单

### 6.1 开单

| 项 | 规则 |
|----|------|
| 谁开 | 员工在楼面看板外卖组分区点桌台开单；客人**不能**自行开台（与堂食一致） |
| 开单内容 | 不填人数、不选自助餐套餐、无自助基价；直接开会话 |
| 开台小票 | 遵循现有开关 `open_table_receipt_print`：开 → 打印外卖开台小票，内容含桌名、时间、**该桌扫码点餐二维码**；关 → 不打印 |
| 堂食开台小票 | **保持现状**（档口单格式、一行合计，无二维码） |

### 6.2 点单

| 项 | 规则 |
|----|------|
| 入口 | 员工代点（楼面桌台详情 → 点餐页 `from=waiter`）或客人扫外卖桌二维码 |
| 页面 | 一律**普通点餐页**；寿司店的外卖桌也不用 `SushiMenuPage`（无轮次界面） |
| 点单模式 | 一律单点：无自助基价、无轮次、`per_person_qty_limit` / `over_limit_unit_price` 不生效 |
| 可见菜品 | 只显示「可外卖」菜品；推荐栏同样过滤；过滤后为空的分类隐藏；菜品时段规则照常生效 |
| 显示价格 | 外卖价 |
| 服务端校验 | 加单按桌台是否外卖桌判定：非可外卖菜品 → 拒绝（`menu_item_not_takeaway`）；单价取外卖价，不信任客户端价格 |
| 购物车失效 | 购物车里的菜在下单前被关掉「可外卖」→ 下单被拒，点餐页提示并移出该菜 |
| 扫码限制 | 地理围栏等现有扫码规则照常 |

---

## 7. 出单

| 项 | 规则 |
|----|------|
| 档口小票 | 照常按档口出单；桌名为外卖桌 `display_name`；**单头标「外卖」** |
| 厨房屏 | 照常显示；外卖桌标「外卖」 |
| 打包商品 | 不进档口小票、不进厨房屏（行类型 `packaging`，见 §10.2） |

---

## 8. 结账

| 项 | 规则 |
|----|------|
| 流程 | 与堂食完全相同：整桌、AA、按菜分单（各付各）均可用 |
| 加打包商品 | 外卖桌结账界面显示「加打包商品」：从打包类选商品 + 填数量，**员工手动**添加；交互参考现有打包费弹窗 |
| 打包商品行 | 单独成行、可改可删（复用现有打包费的写入、防重、作废链路）；名称 / 编码 / 税率取打包商品自身；开票单独成行 |
| 原打包费按钮 | 外卖桌结账界面**隐藏**；堂食桌不变 |
| 分单中的打包商品行 | 与现有打包费行规则一致（实施时核实代码后写明） |
| 权限 | 加打包商品 = 现有加打包费同一权限 |
| 收款 / 开票 / 关台 | 与堂食相同 |

---

## 9. 变更约束汇总

| 操作 | 条件 | 结果 |
|------|------|------|
| 关闭总开关 | 外卖组有未结账桌台 | 拒绝 + 提示 |
| 关闭总开关 | 无未结账外卖桌 | 二次确认后关闭 |
| 外卖组增删组员 / 取消标记 / 删除 | 组内有进行中的会话 | 拒绝 |
| 设第二个外卖组 | 已有外卖组 | 拒绝（置灰） |
| 设打包类 | 有子类别 / 类内有可外卖或推荐菜 / 已有打包类 | 拒绝 |
| 外卖桌 ↔ 堂食桌 转台、并台 | 任意 | 拒绝 |
| 外卖桌加入拼桌 | 任意 | 拒绝 |

## 10. 数据与判定（实施草案）

### 10.1 字段

| 表 | 新增 | 说明 |
|----|------|------|
| `restaurants.feature_flags` | `takeaway_ordering` | 总开关 |
| `restaurant_table_groups` | `is_takeaway boolean NOT NULL DEFAULT false` + 部分唯一索引 `(restaurant_id) WHERE is_takeaway` | 外卖组 |
| `menu_categories` | `is_packaging boolean NOT NULL DEFAULT false` + 部分唯一索引 `(restaurant_id) WHERE is_packaging` | 打包类 |
| `menu_items` | `takeaway_enabled boolean NOT NULL DEFAULT false`、`takeaway_price numeric NULL`（check：enabled 时 > 0） | 可外卖 |

不改 `restaurant_tables`、不加 `table_sessions` 渠道列（变更锁保证会话期间外卖身份不变）。

### 10.2 唯一判定点

| 判定 | 唯一来源 |
|------|----------|
| 桌台是否外卖桌 | 总开关开 **且** 桌台属于 `is_takeaway` 分组 |
| 外卖菜单可见 + 价格 | 客户端 `resolveCustomerMenuCatalogView`（加渠道参数）与服务端 `resolveAppendCartItems` 共用同一定价/可见性函数 |
| 打包商品不进菜单 | 同一 catalog view 排除 `is_packaging` 类别 |
| 打包行不算菜 | 新 `OrderItemKind 'packaging'`；`isMenuCatalogItem` 排除 → 厨房屏、楼面待出餐、菜品历史、排行、点评、寿司限量一次性排除，且不依赖档口配置 |
| 客人可点单门槛 | `guestOrderingEnabled`：有自助餐行 **或** 外卖桌 |

## 12. 实施前待核实（不影响需求，影响实现）

1. **开台小票二维码打印**：当前打印 payload 无二维码字段；需在 farvoo-fatura 确认 Print Agent 是否支持 ESC/POS 二维码，或需新增。
2. **出品单「外卖」标记**：需确认 farvoo-fatura 档口小票模板如何显示。
3. **分单中的打包行**：核实现有打包费行在按菜分单、客人已呼叫后追加时的规则，打包商品行沿用。
4. **转台 / 并台 RPC**：在 `transfer_table_session` / `merge_*` 中加外卖身份一致性校验的位置。

# 开台 / 桌台详情套餐价不晃

## 1. 本次修改

- 桌台详情选项单价与开台共用「可开套餐 + 单价」缓存；当前套餐再用开台锁价覆盖。
- 套餐表单不再逐个查价、不再按分钟重查。
- 选中框固定粗细，只变颜色，切换套餐不顶布局。

## 2. 核心业务规则

- 开台抽屉与桌台详情的选项价来自同一份 openable 名单。
- 已开台桌子：当前套餐显示开台时锁住的单价；其它可开套餐显示当前时段价。
- 选中/未选中边宽相同，只改边颜色。

## 3. 详细测试场景

### 场景 1：进桌台详情价格不晃

- **前置状态**：白云前台已登录；A-01 已开台有人数。
- **操作过程**：从楼面点进 A-01 桌台详情。
- **预期结果**：套餐选项上的成人价/儿童价一次定住，不先空后满、不闪「无匹配价格」。
- **数据验证**：进页后不必再对每个套餐调 `resolve_buffet_prices`。
- **异常恢复**：刷新详情仍一次定住。

### 场景 2：详情切换套餐边不顶布局

- **前置状态**：A-01 详情已打开，未进结账。
- **操作过程**：在 Buffet livre 与 UAT 第二套餐之间来回点。
- **预期结果**：选中金边切换时，卡片高度与下方人数行不上下跳。
- **数据验证**：两边都是 `border-2`，只是颜色不同。
- **异常恢复**：取消换套餐（若未自动保存成功）人数仍正确。

### 场景 3：开台抽屉切换套餐边不顶布局

- **前置状态**：空桌开台抽屉已打开，两个套餐都有价。
- **操作过程**：在两个套餐之间来回点。
- **预期结果**：选中框切换不顶布局；价始终显示，不闪警告。
- **数据验证**：同场景 2。
- **异常恢复**：点取消，桌子仍空。

## 4. 实际测试结果

- 【已验证】`MESA_UAT_BASE=http://localhost:3001`，前台 `qiantai1`，白云。
- 【已验证】开台名单接口：livre 成人 19.95 / 儿童 10，UAT 成人 25 / 儿童 12。
- 【已验证】A-01 详情：两边单价首屏即显示；切换套餐量测高度与 Y 不变，边恒为 2px。
- 【已验证】A-02x 开台抽屉：两边有价；切换套餐布局稳定；取消后桌仍空。

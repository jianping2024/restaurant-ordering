## 2. 核心业务规则

1. **唯一文案**：`formatWaiterBoardOrderedDishQty` → `×N`（无图标）。  
2. **唯一展示位**：view model 字段 `orderedDishQtyText` → 标题行 `cardDishQty`；meta kind 不含 `dishes`。  
3. **显示条件**：就餐中 / 待结账显示（含 `×0`）；空闲不显示。  
4. **不变量**：座位与时长仍在一行 meta；卡高不因份数换行撑开。

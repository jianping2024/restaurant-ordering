| 项 | 内容 |

## 2. 核心业务规则

1. 【本次新增】禁选政策唯一写在各自应用 `globals.css` 的 `@layer base`：`html` → `user-select: none` + `-webkit-touch-callout: none`。
2. 【本次新增】可编辑面恢复：`input` / `textarea` / `select` / `[contenteditable='true']` → `user-select: text`。
3. 【本次新增】只读文案（菜名、规格、订单号展示等）一律不可选中复制；不设白名单。
4. 【已实现】`button` / 楼面桌卡上的 `touch-action: manipulation` 仍保留，但**不再**重复写 `user-select`。
5. 【已实现】业务页不为「全站禁选」再散写第二套 globals 政策。

# 本次改动业务场景测试报告：按菜恢复点单有收款时补打接管标记

日期：2026-10-10 · 分支：`fix/by-item-unlock-set-marker-when-collected` · 环境：本地 Docker Supabase + feature web `:3006`（`MESA_UAT_BASE` / `.next-uat`）· 测试店：白云 `restaurant-mohnrib5`

## 1. 本次修改

- **问题**：上一版（`20261010200000`）有收款时只「不清标签」。若标签本来就是空的（队列只靠未付呼叫票撑着），删掉最后一张未付票后分单变成 `confirmed`，整桌从结账列表消失——桌上明明还有已收款和待收菜。
- **改动**：
  1. 迁移 `20261010210000_by_item_unlock_stamp_marker_when_collected.sql`：解锁后若已无「已呼叫未付」票且这桌有收款流水 → 调用唯一打标函数 `mark_bill_split_staff_checkout`；无收款 → 仍清标签出队。
  2. `shouldHoldCheckoutSessionOpen`：按菜收款时，除池子未分完外，**其他**未付票仍在也 hold（并打标）；排除本次收款人（`personIndex`），避免 `p_hold_open` 把最后一笔的 `all_paid` 打假。
- **唯一写法**：接管标签只由 `mark_bill_split_staff_checkout` 写入；解锁有收款走该函数，不平行 `coalesce` 直写。
- **不在范围**：整桌/均摊会话恢复；新状态枚举。

## 2. 核心业务规则（不变量）

1. 恢复点单只删当前未付票；已付票与收款流水不动。【已实现】
2. 已有收款 + 解锁后无未付呼叫票 → 打/保接管标签 → 分单 `requested` → 仍在结账队列。【本次新增】
3. 从未收款 + 无未付呼叫票 → 清标签 → `confirmed` → 出队。【已实现】
4. 按菜部分收款：还有其他未付票或池子未分完 → hold + 打标；收最后一笔不被错误 hold 卡住。【本次补齐】

## 3. 详细测试场景

### 场景 1：库内对照——有收款、标签原先为空，解锁后仍在队

- **前置状态**：构造分单 `requested`、标签 `null`、一张已付票 + 一张未付已呼叫票、`session_collected_payments` 有 1 笔。
- **操作过程**：对未付票执行 `individual_checkout_apply(unlock)`（事务内回滚）。
- **预期结果**：未付票删除；标签非空；`status=requested`；收款仍 1 笔。
- **结果**：【已验证】pass（`SCENARIO1_PASS status=requested marked=t calls=1 coll=1`）

### 场景 2：库内对照——无收款解锁唯一未付票，出队

- **前置状态**：一张未付已呼叫票，无收款，标签已贴。
- **操作过程**：解锁该票（事务内回滚）。
- **预期结果**：`status=confirmed`，标签空。
- **结果**：【已验证】pass（`SCENARIO2_PASS status=confirmed marked=f`）

### 场景 3：产品 API——有收款、标签为空，员工 unlock-ticket 后仍在队列

- **前置状态**：库内构造 `UAT-stamp`（标签 `null` + 收款 €10 + 未付票 B）；web `:3006`；`qiantai1` 登录。
- **操作过程**：`POST …/checkout/unlock-ticket` 解锁 B；`GET …/checkout/requests`。
- **预期结果**：分单仍在队列；`status=requested`；标签有值；收款 1 笔不变。
- **结果**：【已验证】pass（API `ok`；`in_queue True status requested marked True`；库 `requested|true|1`）

### 场景 4：回归——最后一笔按菜收款仍能结清

- **前置状态**：`UAT-lastpay` 两张未付票、池子无未分菜（无订单行）、标签已贴。
- **操作过程**：`confirm-payment` person 0 再 person 1。
- **预期结果**：第二笔 `all_paid=true`；分单 `paid`。
- **结果**：【已验证】pass（第二笔 `all_paid: true`；库 `paid|all_rows_paid=true`）
